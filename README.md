# ResumeAI — ATS Resume Analyzer

AI-powered ATS Resume Analyzer that evaluates resumes, checks keyword matching, gives ATS scores, and provides AI suggestions to improve interview chances.

## 🔗 Live Demo

🚀 Try here:

[ResumeAI — ATS Resume Analyzer](https://ai-resume-analyzer-livid-six.vercel.app/)

## Features

- ATS Score analysis
- Keyword matching
- Missing keyword detection
- Resume improvement suggestions
- AI-generated bullet points
- Technical skills analysis
- Resume structure checking
- MERN + OpenAI + Gemini integration
- Responsive dark UI

## Tech Stack

Frontend:
- React
- Tailwind CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MongoDB

AI:
- OpenAI API
- Gemini API

Deployment:
- Vercel
